P.C.R.C. NEWS UPDATE — ชุดข่าวพร้อมอัปโหลด

ชุดนี้รวบรวมข่าวที่พบจากแหล่งข้อมูลสาธารณะและเรียบเรียงใหม่สำหรับเว็บไซต์สมาคมปิยะมิตรแม่สายร่วมใจ บรรเทาสาธารณภัยและการกุศล

จำนวนข่าว: 9 รายการ
ช่วงเวลา: พ.ศ. 2562–2569

วิธีอัปโหลดแบบง่าย
1) แตกไฟล์ ZIP
2) นำโฟลเดอร์ PCRC_Netlify_CMS_Source/content/news ไปแทน/รวมกับโฟลเดอร์เดียวกันใน GitHub
3) นำโฟลเดอร์ PCRC_Netlify_CMS_Source/content/sources ไปแทน/รวมกับโฟลเดอร์เดียวกันใน GitHub
4) Commit changes
5) รอ Netlify Deploy จนขึ้น Published
6) เปิด /news.html แล้วกด Ctrl+F5

หมายเหตุ
- ข่าวทั้งหมดเป็นการเรียบเรียง/สรุปใหม่ ไม่ได้คัดลอกบทความต้นฉบับทั้งชิ้น
- แต่ละข่าวมี source_name และ source_url ให้ผู้อ่านตรวจสอบต้นทาง
- ไม่ได้นำภาพจากสำนักข่าวมาบรรจุในชุดนี้เพื่อหลีกเลี่ยงปัญหาสิทธิ์การใช้งานภาพ หน้าเว็บจะใช้โลโก้สมาคมเป็นภาพสำรองจนกว่าจะอัปโหลดภาพของสมาคมเองผ่าน CMS
- ก่อนเผยแพร่จริง แนะนำให้ผู้ดูแลสมาคมตรวจถ้อยคำ วันที่ และรายละเอียดอีกครั้ง โดยเฉพาะข่าวเก่า
