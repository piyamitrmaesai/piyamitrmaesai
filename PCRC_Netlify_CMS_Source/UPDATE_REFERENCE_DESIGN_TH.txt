P.C.R.C. — ชุดอัปเดตดีไซน์ตามภาพตัวอย่าง
============================================

เวอร์ชันนี้ปรับหน้าเว็บไซต์ให้ใช้รูปแบบเดียวกับภาพตัวอย่างที่อนุมัติ ได้แก่
- Header น้ำเงินเข้ม 2 ชั้น พร้อมโลโก้ ชื่อสมาคม ข้อมูลติดต่อ และเมนูเส้นเหลือง
- Hero ภาพกู้ภัย + ข้อความใหญ่ + โลโก้ P.C.R.C. ด้านขวา
- แถบข้อมูลสำคัญพื้นเหลือง 4 ช่อง
- ส่วนภารกิจ 4 การ์ด และข่าวล่าสุด 3 การ์ดในแถวเดียวกันบนจอใหญ่
- แถบสมัครอาสาสมัคร / ร่วมบริจาคสีเหลือง
- Footer น้ำเงินเข้ม พร้อมเมนู ติดต่อ Facebook และพื้นที่ QR Code
- Responsive สำหรับมือถือและแท็บเล็ต
- ไม่มีเมนู/หน้า “ศูนย์สื่อสาร”
- ระบบ /admin/ และการแก้ข้อความ/รูปภาพยังใช้งานได้ตามเดิม

วิธีอัปเดตเว็บไซต์เดิมบน GitHub
--------------------------------
1) แตกไฟล์ ZIP
2) เปิดโฟลเดอร์ PCRC_Netlify_CMS_Source ที่ได้จาก ZIP
3) นำไฟล์/โฟลเดอร์ข้างในไปแทนไฟล์เดิมใน PCRC_Netlify_CMS_Source บน GitHub
4) กด Commit changes
5) รอ Netlify Deploy จนขึ้น Published
6) เปิดเว็บไซต์และกด Ctrl + F5

ค่า Netlify ใช้ค่าเดิม
----------------------
Base directory: PCRC_Netlify_CMS_Source
Build command: npm run build
Publish directory: dist
Functions directory: netlify/functions

การแก้ Hero จาก Admin
----------------------
เข้า /admin/ > เนื้อหาหน้าเว็บไซต์ > หน้าแรก
สามารถเปลี่ยน:
- ข้อความ Hero
- รูปพื้นหลัง Banner / Hero
- ปุ่มหลัก / ปุ่มรอง
- ข้อมูลสำคัญ 4 ช่อง

หมายเหตุเกี่ยวกับภาพตัวอย่าง Hero
---------------------------------
ไฟล์ assets/hero-rescue-demo.webp เป็นภาพประกอบดีไซน์สำหรับให้หน้าเว็บมีหน้าตาใกล้เคียงภาพตัวอย่าง
แนะนำให้ผู้ดูแลเปลี่ยนเป็นภาพปฏิบัติงานจริงของสมาคมจาก Admin ก่อนเผยแพร่เป็นเว็บไซต์ทางการ

ข้อมูลโทรศัพท์ / อีเมล / LINE / QR บริจาค
-------------------------------------------
ระบบจะไม่สร้างข้อมูลขึ้นเอง หากยังไม่ได้กรอกข้อมูลจริง ระบบจะซ่อนส่วนนั้นไว้
แก้ได้จาก /admin/ > ตั้งค่าเว็บไซต์
