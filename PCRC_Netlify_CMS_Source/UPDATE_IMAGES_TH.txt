P.C.R.C. CMS — อัปเดตแก้รูปภาพแต่ละหน้าได้จาก Admin

สิ่งที่เพิ่ม
- ทุกหน้า: อัปโหลด “รูปพื้นหลัง Banner / Hero” ได้
- หน้าเกี่ยวกับเรา / ภารกิจ / ข่าวสาร / ศูนย์สื่อสาร / อาสาสมัคร / ร่วมบริจาค / ดาวน์โหลด / ติดต่อเรา: มี “รูปประกอบเนื้อหา”
- หน้าแรก: มี “รูปเด่นด้านขวาหน้าแรก” และ “รูปประกอบส่วนภารกิจหน้าแรก”
- มีช่อง Alt text สำหรับรูปประกอบ เพื่อช่วยการเข้าถึงและ SEO
- ถ้าเว้นรูปว่าง เว็บไซต์จะใช้ดีไซน์เดิม

วิธีอัปเดต GitHub (สำหรับโครงสร้างที่ใช้อยู่)
1) แตกไฟล์ PCRC_CMS_UPDATE_PAGE_IMAGES.zip
2) จะเห็นโฟลเดอร์ PCRC_Netlify_CMS_Source
3) นำไฟล์/โฟลเดอร์ด้านในไปแทนไฟล์ชื่อเดียวกันใน PCRC_Netlify_CMS_Source บน GitHub
4) กด Commit changes
5) รอ Netlify Deploy จนขึ้น Published
6) เปิด https://piyamitrmaesai.netlify.app/admin/ แล้วกด Ctrl+F5

วิธีเปลี่ยนรูป
1) เข้า Admin > เนื้อหาหน้าเว็บไซต์
2) เลือกหน้าที่ต้องการ
3) ที่ “รูปพื้นหลัง Banner / Hero” กด Choose an image / Select image
4) อัปโหลดรูป แล้วเลือกใช้
5) ถ้าต้องการรูปในเนื้อหา ให้เลือก “รูปประกอบ...”
6) กด Save / Publish
7) รอ Netlify Deploy ใหม่จน Published
8) Refresh หน้าเว็บไซต์

แนะนำขนาดรูป
- Banner / Hero: 1920 x 800 px หรืออัตราส่วนประมาณ 2.4:1
- รูปประกอบแนวนอน: 1600 x 900 px (16:9)
- หน้าแรก รูปเด่นด้านขวา: 1200 x 1200 หรือ 1200 x 1500 px
- JPG / WEBP เหมาะสำหรับภาพถ่าย และควรบีบไฟล์ให้ไม่ใหญ่มากเพื่อให้เว็บโหลดเร็ว

หมายเหตุ
- รูปที่อัปโหลดจะถูกเก็บใน PCRC_Netlify_CMS_Source/assets/uploads
- หลัง Publish ต้องรอ Netlify Build/Deploy ก่อนรูปใหม่จึงจะปรากฏบนเว็บ
